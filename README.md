# Halo 4 Keymapping Editor

A basic application to patch Halo 4 TagTest and Sapien player character keybindings.

Important notes
* Requires NET 8
* Does not support tag_play or sapien_play
* Whilst I have tested the application, it's worth keeping a backup of your executables just in case.
  * If anything does go wrong and you don't have backups, you can still verify integrity with Steam
    
* Some keybindings will not be accepted by the game
   * For example, Sprint by default is bound to C but will not work - it only appears to accept modifier keys ie shift, control, alt
     
* I have only mapped out some of the main bindings. Check show unknowns in the preferences menu to see all the available bindings that can be patched
  * Feel free to submit an issue if you discover what any of them correspond to
